# Project Evidence Graph v0.2.0

The first public packaged release provides deterministic project traceability and assurance from requirements through implementation, tests, changes, defects, and retained evidence.

## Highlights

- Installed Python CLI with traceability, path, impact, review, lifecycle, and pack commands.
- Explicit import and cross-repository composition contracts with provenance and conflict diagnostics.
- Quality, freshness, risk, and stale-by-change assurance in one review.
- Integrity-verifiable bounded evidence packs and historical comparison.
- Synthetic enterprise/SAP-shaped examples and public browser explorer.

## Verify

Run the [golden quickstart](../docs/GOLDEN_QUICKSTART.md). Release assets include a reproducible wheel, a deterministic source archive, and checksums from the tagged commit.

## Compatibility and non-goals

This is a `0.x` alpha. It does not infer missing links, certify delivery readiness, replace source systems, or turn pack integrity into business acceptance.
